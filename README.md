# 学做网站 · 三个成品

用三种方法学做网站的练手项目，暂不发布上线。

## 成品一览

| # | 方法 | 成品 | 路径 | 说明 |
|---|------|------|------|------|
| ① | 复刻 | 阿宝姐AI大赛页面（深空科技感） | `复刻版_可编辑.html` | 纯手写 HTML/CSS 单文件 |
| ② | 工具建站 | 杨杨的网站 | `my-docs/` | VitePress 个人站 |
| ③ | Skills 动态站 | 百元男装官网（黑金高级风） | `333/index.html` | Tailwind + Lucide 图标 |

## 本地运行

- ①③ 直接双击打开 HTML 即可
- ② 需先装依赖再启动：

  ```bash
  cd my-docs
  npm install
  npm run docs:dev
  ```
